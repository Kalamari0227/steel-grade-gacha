# 학습 조사안

상태: 실행 전 설계안. 참여자 모집·연락·녹음·분석 수집을 하지 않았고 측정된 학습효과를 주장하지 않는다.

## 목적과 대상 구분

앱의 조작 사용성과 개념 이해를 분리해서 확인한다. 신입군은 철강 업무 경험이 없거나 짧은 사람, 경력군은 관련 실무 경험을 가진 사람으로 구분하되 실제 조사 전에 기준과 동의 절차를 확정한다. 직무·경력 자기보고를 최소 항목으로 받고 개인 식별정보는 필요할 때만 별도 승인한다. 아래 계획은 조직 내 평가·인사판정 용도가 아니다.

## 실행 전 준비

최종 T23 산출물 SHA, 기기/뷰포트/접근성 설정, 사용할 고정 상태(신규·재고0·QP보유 등)를 고정한다. 정답표는 원본 데이터와 카드 표시를 따르며 실물 소재 선정의 자격 시험으로 사용하지 않는다. 첫 설명·힌트·과제 순서·시간제한·중단 기준을 사전에 정하고, 앱 사용 전/후에 동일 문장을 그대로 반복해 암기효과를 키우지 않도록 동등한 형태의 과제를 준비한다.

## 과제와 채점표

각 과제0–2점, 총12점의 제안이다. 점수 기준은 실행 전에 확정하고 사후 결과에 맞춰 바꾸지 않는다.

|---|---|---|---|
| 도감/재고 |재고0 CQ를 찾고 발견은 남지만 당장 소비할 재고는 없다고 설명 |한 의미만 정확 |재고0=미발견 또는 사용가능이라고 설명 |

## 사용성 관찰

별도 표에 과제 성공 여부, 첫 행동까지의 시간, 경로 이탈, 잘못된 클릭, 힌트 횟수, 포커스 손실, 오류 후 복귀를 기록하도록 설계한다. 자발적 설명과 관찰자의 해석을 분리하고 불편 응답을 낮은 학습능력으로 해석하지 않는다. 키보드·큰글자·감소동작 조건은 참여자의 선택/필요에 따라 기록한다.

## 학습효과 검토 방법과 한계

사전·사후 개념 점수, 지연 과제, 오개념 빈도를 사용성 결과와 분리해 비교하는 방법을 제안한다. 집단 비교를 하려면 배정 방법·표본계획·누락 처리·연습효과·경력 차이를 미리 정해야 한다. 작은 편의표본의 개선만으로 현장성과나 장기학습을 입증할 수 없다. 현재는 표본수·결과·효과크기·유의확률을 만들지 않는다.

## 산출물 제안

익명 과제 기록표, 사전에 고정한 채점표, 관찰 메모, 조작 오류/개념 오류 분리표, 한계 보고서를 사용한다. 모집·동의·데이터 보관/삭제·분석의 실제 실행은 별도 승인 후 진행한다.

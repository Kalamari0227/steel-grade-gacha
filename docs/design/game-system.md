# Steel Companion 게임 디자인 시스템

승인된 금속 피규어·카드 시안 다섯 장을 게임 전체로 확장하는 구현 계약이다. 시안의 색·빛·구도는 기준이며 그림 속 숫자·차량·보유량은 샘플이다. 실제 게임은 기존 상태와 경제 함수를 읽는다. 이 문서 작성이나 프로토타입의 클릭 성공은 제품 구현 완료를 뜻하지 않는다.

`#learn`, `#learning`은 `replaceState`로 `#research`에 정규화한다. 별칭 자체를 새 방문기록으로 쌓지 않는다. 잘못된 hash는 공방으로 정규화하고 Back/Forward·새로고침은 선택 화면만 복원한다. 경제 행동을 URL 탐색으로 실행하지 않는다. 설정은 탭이 아니며 모든 목적지에서 도달 가능한 대화상자다. 설정·카드·부품·보증·웹툰을 닫으면 호출한 route와 조작에 초점을 돌린다.

### 도감 감상 화면 구현 계약

`전체 그리드`와 `큰 카드 감상`은 같은 필터와 선택 ID를 공유한다. 큰 카드 모드에서는 계열 선택과 `추가 필터`를 먼저 보여 주며 LV·발견·재고 조건은 펼쳐서 변경한다. 발견 진행은 일반44+QP1의45종이며 미발견 QP의 실제 공개 조건은 그대로다. 문서가 세로 스크롤을 소유하고, 추가 필터가 접힌390×844/1280×900 첫 화면에서는 전체 카드와 이전·다음 조작을 하단 내비게이션 위에 둔다. 낮은 높이와200% 상당 재배치에서는 카드 크기를 지나치게 축소하지 않고 문서 스크롤로 모든 내용을 읽는다.

큰 카드와 양옆 힌트는 공용 합성기의 기본 `card` 변형과8개 독립 레이어를 쓴다. 힌트는 발견한 이웃 소재에만 표시하고 미발견 정보를 공개하지 않는다. 장식용 힌트는 inert이며 조작은 이전·다음 버튼으로 제공한다. 그리드 썸네일은 매니페스트의 파생 이미지를 지연 로드한다. 상태 변경 후 모든 합성기 handle을 해제하고, 이미지 실패는 실제 재시도와 현재 면의 HTML 물성으로 설명한다. 전환은180ms ease-out/24px 이내 이동이며 감소모션에서는 즉시 바뀐다. 좌우 방향키·44px 이전/다음 버튼은48px 수평 스와이프와 같은 필터 범위에서 작동한다. 일반 프레임에 별도 가짜 foil 효과를 추가하지 않는다.

`장비 보기`와 `만들 수 있는 부품`은 기존 카드 대화상자의 호환 장비/원본 부품 후보를 펼친다. 장착 대상 선택과 제작 검토는 원래 기능을 호출한다. 대표 전시는 `GAME_HOME.select`로 환경설정만 바꾸며, 도감 탐색은 진행을 저장하지 않는다.

### 제작대 구현 계약

제작 탭은 기존 바디10·프레임10·섀시/구동15 부품을 실제 완료/가능/부족 상태로 표시한다. 위치도에는 `S.parts`에 기록된 부품만 승인된35개 raster와 assembly metadata의 개략 좌표로 놓는다. disc는 프레스 성형 휠 중심판, brake는 마찰재와 강판 백킹이며 둘을 교체하지 않는다. 전시 배치는 실제 설계도나 주행 차량을 뜻하지 않는다.

제작 대화상자는 원본 슬롯 후보·선택 소재·합산 사용량·현재 재고 전후를 보여 준다. 후보와 소재 상세는 별도 버튼이다. QP 연구에서 취소하거나 개발 결과를 명시적으로 닫으면 원래 부품/선택/스크롤로 돌아오고, 표시 이후 수량이나 선택 유효성이 달라졌으면 현재 비용을 다시 검토한 후 확정해야 한다. 경로 이동·진행 교체·다른 부품 진입은 이전 복귀 문맥을 취소한다.

기존 craft/save 뒤의 표시 전용 연출은0ms 재료,300ms 형성,650ms 위치 결합,1100ms 완료를 쓴다. 위치 이동은450ms ease-out transform, 등장 opacity는180ms이며 재고 추가 소비나 실패 확률은 없다. 바로 완성 보기는 즉시 최종 상태로 바꾸고, 감소모션에서는 타이머/효과음 없이 완성을 보여 준다. 닫기/탭 숨김/페이지 종료는 자기 타이머·이미지·리스너를 정리한다. 이미지 실패와 재시도는 `.craft-art`가 단독 소유하며 일반 PWA 이미지 fallback과 중복하지 않는다.

## 화면 구성

390×844 모바일은 제목·설정, 현재 자원/문맥, 주요 피규어 또는 작업대, 다음 행동, 5탭 순서다. 하단 내비게이션의 safe-area와 실제 높이만큼 본문 여백을 둔다. 큰 그림 때문에 비용·오류·닫기 버튼이 밀려 사라져서는 안 된다. 1280×900에서는 동일 정보 순서를 유지하며 장면과 조작 패널을 두 열로 나눈다. 360×800·768×1024·200% 확대·낮은 높이에서는 단일 열과 내부 스크롤로 모든 조작에 접근한다.

- **공방:** 실제 대표 소재 한 명과 실제 보유차를 선택적으로 전시한다. 최초 대표는 catalog 순서의 첫 발견 ID다. 신규 상태에는 공방 도구/비어 있는 받침을 쓴다. 출하 가능 여부로 1회 또는 10연 중 주행동 하나를 강조하되 두 버튼의 비용/잔여를 항상 읽을 수 있게 한다. 추천은 `homeRecommendation`/`partPlan`으로 가능한 다음 부품 하나를 보여준다.
- **도감:** 격자와 갤러리는 같은 필터/선택 ID를 공유한다. 큰 카드 양쪽의 다음 카드 일부 노출은 방향 힌트이며 이전/다음 버튼도 제공한다. 이름·계열·LV·재고·물성은 HTML이다. 재고0이어도 발견 카드의 학습 정보는 유지한다. 장비 보기와 만들 수 있는 부품을 분리한다.
- **제작:** 왼쪽 또는 상단에는 부품 분류/35개 진행, 오른쪽 또는 하단에는 선택 부품·슬롯별 재고·선택 전후 소비를 둔다. `제작 검토` → `제작 확정 / 취소`가 명료해야 한다. QP 링크는 연구로 이동한 뒤 원래 picks를 복원한다. 35개 완료는 차고 조립 CTA로 연결한다.
- **연구:** 퀴즈·주문·보증·QP·웹툰을 실제 한도와 조건으로 배치한다. 퀴즈는 5문제 흐름/해설/재도전, 주문은 요구/보증 답/획득/장착·나중에, QP는 공개조건/재료/개발확정, 웹툰은 3항목 목록/회차/도감연결 복귀다. 탭에서 숨겨져 기능이 사라지지 않게 한다.

연구 첫 화면은 네 활동 바로가기 다음에 실제 연구실 원화와 퀴즈를 둔다. 문서가 스크롤을 소유하고, 넓은 화면에서는 퀴즈·웹툰과 고객 요구·QP가 두 열, 좁은 화면에서는 같은 순서의 한 열이다. 그림 높이는 모바일120px/넓은 화면240px이며 주요 퀴즈 버튼은390×844와1280×900에서 하단 내비게이션 위에 남긴다. 퀴즈 잔여는 첫 보상부터24시간 주기, 고객 요구는 달력 날짜 기준임을 구별한다. 조건 목록과 소재 상세는 실제 발견 상태를 읽는다. QP 검토 중 소재 카드를 닫으면 선택과 초점을 유지하고, 제작에서 공개 과제를 열었으면 취소 뒤 제작 호출 버튼으로 돌아간다. 정오답 효과음은 최초 채점, 보상 효과음은 실제 지급과 저장 시도 뒤 한 번만 재생한다. 이미지와 소리가 실패해도 원래 결과·비용·설명은 유지한다.
- **차고:** 미보유는 덮개·실루엣 잠금과 남은 부품, 보유는 실제 차종·획득일. 35부품 완료 후 선택은 소비0, 확정만 차량 추가·부품 초기화다. `대표 전시로 선택`은 보유차에만 나타난다.
- **설정:** 소리 켜기/무음·전체 mute·BGM/SFX, 출하 알림, 백업/게임 복원/교육용 가져오기/회복코드, 설치, 공지/행사, 초기화 순으로 의미를 묶는다. 데이터 교체와 초기화는 각각의 요약/확인을 사용한다. 설정 중 다른 화면으로 돌아갈 명시 닫기 버튼을 둔다.

프로토타입의 제작·연구·차고·설정 화면은 **시안용 가상 재고/차량**으로 표시한다. 공방/도감의 승인 이미지는 참조 자료다. 프로토타입 자산 재사용은 임시 참조에 한하며 제품은 새 분리 원화로 교체한다.

## 규칙·연출 경계

출하·10연·교환·개발·장착·제작·차량 획득은 기존 함수로 먼저 확정하고 저장을 시도한 뒤 연출한다. 소리/그림 실패·스킵·닫기·탭이동·재진입이 재추첨·중복 지급·차감으로 이어지면 실패다. 저장 실패는 경고와 현재 메모리 결과·백업 접근을 보장한다. 저장을 원자적 영속 트랜잭션으로 과장하지 않는다.

기본/추가 출하, 스크랩, stock/owned, `partPlan`, QP 대체, 주문/퀴즈 한도, 확률/물성/레시피를 보존한다. 일반 POOL44 + 개발전용 QP1 = 소재45, 열처리 alt2를 포함해47면이다. LV는 사업 등급이고 전투력 순위가 아니다. SSR·별·ATK·전투·유료재화·새 보상·장착해제/재배치를 도입하지 않는다.

## 오디오·동작·접근성

첫 방문은 무음이다. `소리 켜기`와 `무음으로 계속`을 동등하게 제공한다. 동의 후 기본 BGM30%/SFX60%, 독립 슬라이더·전체 mute를 게임 전용 preferences에 저장한다. BGM은 공방/도감·연구/장비·제작/차고 네 역할, 효과음은 승인된24개 cue다. 짧고 웅장한 소리는 공개·완성에 사용하고 중요한 텍스트를 가리지 않는다. 숨김/pagehide에서 소리를 중단하고 복귀 시 놓친 효과음을 재생하지 않는다. 재생 실패는 명시 탭복구를 제공한다.

개봉·뒤집기·장착·조립에는 스킵 또는 즉시 결과 접근이 있다. `prefers-reduced-motion`에서는 tilt/시차/smooth scroll/지연을 없애고 결과를 즉시 표시한다. 터치 스와이프에만 기능을 두지 않는다. Tab/Shift+Tab으로 읽는 순서, Enter/Space 작동, Escape 닫기, 최상단 대화상자 초점순환과 원래 조작 복귀를 유지한다. 로딩은 live status, 오류는 해당 입력과 연결된 설명으로 제공한다.

## 저장·부분 오프라인 안내

게임 진행은 `sgg_game_save_v1`, IDB `sgg_game`/`save`, 웹툰 `sgg_game_toon_seen`, 환경 `sgg_game_preferences_v1`, 설치 `sgg_game_install_dismissed`/`sgg_game_installed`로 분리한다. 교육 저장 자동 읽기/가져오기는 없다. 게임 복원 `SGG-GAME1.`와 명시 교육 가져오기 `SGG1.`를 구분하며 검증/요약/이전 회복코드/교체 확인을 거친다. 전체 취소는 진행 불변이다.

업데이트는 유휴 시 안내하고 진행 중인 출하/가져오기를 강제 재로드하지 않는다. 미캐시 그림에는 텍스트·계열 대체와 재시도, 미캐시 오디오에는 무음, 최초 미캐시 방문에는 재연결 안내를 제공한다. 실제 오프라인 범위와 실제 설치 결과만 말한다.

## 장비 미리보기

미장착 보증에서 호환 소재를 선택하면 큰 피규어와 받침 위에서 `장착 전 / 미리보기`를 전환한다. 현재 장비는 두 상태에 모두 남고 후보만 추가된다. 공방 원화를 배경으로 stage variant를 사용하며 일반 도감 카드의 프레임은 유지한다. 모바일 첫 화면은 짧은 소재 제목, 44px 비교 버튼, 전신, 선택 보증 이름과 재고 무소모 안내, 장착 확정·취소 순서다. 상세 보증 설명·호환 보유 장비·다른 소재 선택은 아래에 둔다. 선택은 체크와 aria-pressed·선택 표면으로 표시한다. 확정 전 임시 선택은 저장하지 않으며 오류·재시도 상태는 렌더 핸들의 live status로 갱신한다. 데스크톱은 전신과 장비 설명을 두 열에 둔다.

### 차고 전시 구현 계약

차고의 실제 장면은 신규 차고 배경·전경, 분리 받침, 보유 차량 원화를 쓴다. 1200×800 자동차는 contain으로 바퀴까지 보존하고 작업대 위에 놓는다. 빈 차고는 도구와 빈 받침만 표시한다. 전체 여덟 칸의 미보유 미리보기는 잠금 문구를 유지하며, 대표 전시는 보유 차량에만 허용한다. 35부품 선택 검토와 최종 확정을 분리하고 수량 35→0을 읽을 수 있게 한다.

출고는 저장 시도 뒤 1500ms의 조명·작은 각도 전시 회전으로 끝난다. phase는 light→turntable→complete이고 바로 완성 보기로 즉시 종료한다. 감소모션은 즉시 정적 결과, 숨김/페이지 이탈/대화상자 교체는 타이머·이미지 요청을 해제한다. 출고와 별개인 상태 문구가 최종 결과를 유지한다. 차고 아트는 자체 오류/재시도 소유자를 가지며 PWA 전역 오류 처리와 중복되지 않는다. 본문 스크롤과 기존 44px 이상 조작, 어두운 표면/샴페인 강조 토큰을 유지한다.

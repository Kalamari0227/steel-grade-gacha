# 처음부터 다시 설계한다면 · 방향 시안 (2026-11-15)

**상태: 사용자 확정(2026-11-15 "이 방향으로 적용"), 체험판에 반영.** 반영 내용과 시안과 달라진 점은 체험판 `DESIGN.md`의 "U4 밝은 출하 검사장" 절에 있다. 아래는 확정 전 제안 원문이다. [시안](index.html)은 정지 화면 다섯 장(로비·출하소·도감·상세·제작, 390px)이다. `game-edition/`을 정적 서버로 띄우고 이 폴더의 `index.html`을 직접 연다(루트 주소를 열면 이전 게임의 서비스 워커가 등록된다). 그림은 체험판 `data.json`의 승인 대상 ID로만 불러오고 복사하지 않았다. 수치와 보유 상태는 예시다.

## 왜 다시 생각하는가

사용자 검토(2026-11-15): "화면 UI가 특히 별로다", "글꼴이 아동용도 어른용도 아니다", "명일방주 같은 비장함이 차라리 낫다", "밝게 간다면 블루 아카이브도 참고가 된다".

원인은 색이 아니라 **정체성이 정해지지 않은 것**이다.

- 주인공은 광택 나는 금속 수집 피규어다. 둥글고 웃는 얼굴이며 계열색 선과 육각 표식을 가졌다.
- 지금 껍데기(U1·U2)는 짙은 금속판·황동·명조 제목으로 무게를 잡는다. 귀여운 피규어와 톤이 어긋나 어느 쪽 독자에게도 맞지 않는다.
- 2026-11-15의 임시 밝은 테마(체험판 CSS의 U3 블록)는 종이색 바탕과 흰 판으로 돌아가, 11월 14일 계획이 "웹 문서처럼 보인다"고 지적한 상태에 가까워졌다. 색만 바꾼 것이라 정체성 문제는 그대로다.

## 개념: 밝은 출하 검사장

이 게임만 가진 재료는 **실제 철강 현장의 말과 서류**다. 강종 번호(1470H), 물성 단위(MPa·%), 출하·검사·보증·작업지시라는 용어가 이미 게임 안에 있다. 이것을 화면 문법으로 쓴다.

| 화면 | 현장의 서류 | 효과 |
| --- | --- | --- |
| 출하소 | 코일 태그 | 뽑기가 "출하"로 읽힌다 |
| 상세 | 검사증명서(밀시트) | 물성 정보가 장식이 아니라 주인공이 된다 |
| 도감 | 강종 대장 | 빈칸이 "모을 것"으로 읽힌다 |
| 제작 | 작업지시서 | 지금 할 일이 맨 위에 온다 |
| 차고 | 출고증 | (시안 없음. 같은 문법으로 만든다) |

비장함은 **절제**에서 온다(먹색 괘선, 큰 번호, 한 가지 강조색). 밝음은 **검사장 조명**에서 온다(밝은 회색 바닥, 흰 서류). 엄격한 서류 위에 귀여운 피규어가 서는 대비가 이 게임의 표정이 된다. 특정 게임의 배치·아이콘·색을 옮기지 않는다는 11월 14일 원칙은 유지한다.

## 체계

- **색**: 바닥 `#e8eaeb`, 서류 `#f8f8f5`, 먹 `#14181d`, 보조 `#57606a`. 강조는 안전 노랑 `#f5b700` 하나이며 **화면당 주 행동 한 곳**에만 쓴다(노랑 위 글자는 먹색). 선택 상태는 먹색 반전이다. 도장 빨강 `#b3261e`는 "발견·합격" 표시에만 쓴다. 계열색 6종과 등급색은 기존 값을 유지하되, 계열색은 그 동료의 화면에서 띠·게이지·인용선으로만 쓴다.
- **글자**: 강종 번호와 숫자는 좁은 산업용 숫자체(시안은 기기에 있는 DIN 계열)로 가장 크게. 한글은 굵은 고딕 한 종(시안은 Noto Sans KR 400·700·900). 작은 영문 라벨은 고정폭. 명조는 카드 글귀(승인 표현)에만 남긴다.
- **모양**: 둥근 모서리를 없애고 모서리를 딴 강판 모양을 주 행동과 지시서에만 쓴다. 판은 그림자 대신 1px 실선과 2px 먹색 머리선으로 구분한다.
- **독**: 선 아이콘 한 벌(시안은 SVG 자리 표시)과 한글·영문 두 줄 라벨. 승인 그림을 줄여 쓴 지금의 아이콘은 크기와 화풍이 서로 달라 가장 먼저 바꿀 대상이다. 연구는 열리기 전까지 잠금으로 표시한다.
- **연출**: 봉인을 여는 순간부터는 지금의 어두운 무대를 그대로 쓴다. 밝은 화면에서 암전되므로 대비가 커진다.

## 바뀌지 않는 것

경제·저장·확률·연출 길이·카드 구성(무대·전신·프레임·글귀)·승인 원화. 조작 영역 44px, 키보드·초점 복귀, 감소모션, 소리 기본 꺼짐. 미발견 동료는 계열 실루엣과 계열명만 드러낸다.

## 사용자가 정할 것

1. **방향**: 이 개념으로 갈지. 아니면 섞을 부분(예: 더 따뜻하게, 덜 딱딱하게).
2. **강조색**: 안전 노랑(시안) / 기존 황동 `#f5cc75` / 파랑.
3. **숫자·번호 글꼴**(확정: Barlow Condensed 700을 체험판에 넣음. 이 시안 파일은 여전히 기기 글꼴로 그린다): 시안은 기기 글꼴이라 다른 기기에서는 다르게 보인다. 저장소에 넣을 좁은 숫자체 1종을 고르고 내려받는 승인이 필요하다(후보: Big Shoulders Display, Barlow Condensed, Oswald — 모두 OFL로 알려져 있으나 허가서 본문은 받을 때 확인한다).
4. **독 아이콘**: SVG 선 아이콘으로 확정할지, 그림 아이콘을 새로 승인받을지.
5. **영문 소제목**(SHIPMENT, INDEX 등)을 둘지.

## 확정되면 고칠 문서

- 체험판 `DESIGN.md`: 지금은 "이 절이 위를 대체한다"가 여섯 겹 쌓여 현재 상태를 한 번에 읽을 수 없다. 원칙 → 토큰 → 부품 → 화면 순의 현재형 한 벌로 다시 쓰고 이력은 뒤로 뺀다.
- `docs/plans/game-ui-redesign-plan-2026-11-14.md`의 "U1에서 정하는 디자인 체계" 표와 `docs/design/game-system.md`의 시각 토큰(둘 다 어두운 바탕 기준).
- `docs/design/system.md`는 이전 계열의 밝은 문서형 계약이다. 게임판의 기준으로 인용하지 않는다.

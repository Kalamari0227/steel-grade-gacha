주행 그림 시안 (관문 3)

주행 화면의 내 차 뒷모습을 어떻게 그릴지 고르는 시안입니다. 지금 시제품(v4)은 차 8대가 같은 모양에 폭과 색만 다릅니다. 아래 A안은 차급마다 실루엣·후미등·지붕을 따로 그린 코드 도트입니다(새 그림 파일 없음, 색은 승인된 차 그림에서 뽑음). B안은 뒷모습 원화를 새로 받는 방법으로, 유료 생성과 승인 기록이 필요해 이 시안에서는 만들지 않았습니다. 이 화면은 정지 시안이고 게임에는 아직 아무것도 넣지 않았습니다.

1. 차 8대: 지금과 A안

왼쪽이 지금, 오른쪽(노란 테)이 A안입니다. 둘 다 주행 화면과 같은 크기를 3배로 키웠습니다.

2. 주행 화면에 놓았을 때

320×200 화면에 A안 차를 실제 크기로 놓은 모습입니다(도로는 간단히 그린 자리 표시). 위는 내 차, 길 위의 작은 차는 같은 그림을 줄여 쓴 경쟁 차입니다.

3. 고를 것

A. 다듬은 코드 도트 권장
  • 비용 없음, 그림 파일·승인 기록 없이 코드로 들어갑니다.
  • 차급이 한눈에 구별됩니다(미니밴·SUV·세단·해치백·경형·로드스터).
  • 기울임·부스트·자국을 코드로 바로 바꿀 수 있습니다.
  • 승인된 차 그림의 광택 있는 미니어처 느낌과는 다릅니다(도트 화면 전용).
B. 뒷모습 원화 8장 새로 받기
  • 승인된 차 그림과 같은 질감으로 맞출 수 있습니다.
  • 유료 생성이고, 장마다 대상 ID·SHA·사용자 승인이 필요합니다.
  • 320×200 도트 화면에 넣으려면 줄여서 도트로 바꾸는 손질이 필요하고, 기울임 그림은 따로 받아야 합니다.
  • 차·회사 이름이 드러나지 않게 다시 확인해야 합니다.
C. A로 본편에 넣고, B는 나중에
  • 관문 4(본편 적용)를 그림 때문에 미루지 않습니다.
  • 원화는 성적서·차 고르기처럼 큰 그림이 보이는 곳에만 나중에 씁니다.

B안을 고르시면 쓸 요청 글 초안(한 대 기준, 생성은 하지 않았습니다):

승인된 [차 이름] 그림과 같은 차를 정확히 뒤에서 조금 위(약 15도)에서 본 모습. 같은 색·같은 휠·같은 질감의 진열용 미니어처.
배경 없음(투명), 차 전체가 화면 안에, 좌우 대칭, 그림자 없음. 회사 로고·차 이름·번호판 글자 없음.

4. 이 시안에 없는 것

길가 물체(가로등·나무·코일 더미)와 먼 배경, 장애물·대차 그림은 이번 시안에서 다루지 않았습니다. 차 그림 방향이 정해지면 같은 방식으로 이어서 보여 드립니다.

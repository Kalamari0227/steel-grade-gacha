# 타래 9종 r2 정적 원화 검토 자료

이 문서는 게임 UI가 아닌 아트 검토 자료의 표시 계약이다. 사용자 지시의 단순 정적 페이지 범위만 구현한다.

- 흐름: 범위·대기 상태 → 실제 72px 9종 → CHQ/SWRH 전후 → 전신 9종 → 출처.
- 색: 배경 #f5f3ef, 종이 #ffffff, 본문 #242424, 보조 #56534e, 링크 #735321, 중립 구분선 #d8d4ce.
- 글꼴: 로컬 시스템 sans-serif. 크기 14, 16, 20, 24, 28, 32px. 행간 1.65, 제목 1.25/1.4.
- 간격: 4px 단위, 8/12/16/24/32/48px. 콘텐츠 최대 1080px, 좌우 여백 24px.
- 반복 요소: 72px figure, 전신 figure, 두 칸 전후 비교. 그림 밖에 ID·강종·버전을 표기한다.
- 원화는 배경을 포함한 전체 프레임으로 표시한다. native72는 실제 72×72 파일을 CSS 72×72로 표시하며 확대하지 않는다. 1024×1536 전체가 48×72로 들어가고 좌우 12px 여백을 둔다.
- 반응형: 9종은 자동 줄바꿈, 전신 3→2→1열, 비교는 2열 유지하되 원화가 폭에 맞춰 줄어든다. 페이지 전체에만 세로 스크롤.
- 접근성: 한국어 lang, 제목 계층, 설명 alt, 원본 링크, 기본 키보드 포커스. 모션·스크립트·컨트롤 없음.
- 승인: 모두 사용자 승인 대기. 방향 승인만 반영. 생산 교체·장착 모습·게임 개발 승인 없음.
- 검증: HTTP 바이트, 9 ID 매핑, 72px 실측, 이미지 로드, 모바일 가로 넘침과 실제 캡처. 정적 검토 자료에 제품용 리서치·기능·애니메이션을 추가하지 않는다.

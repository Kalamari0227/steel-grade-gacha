# 게임판 계약 개정 대조표 (초안) · 2026-11-14

**상태: 초안.** 체험판(`.omo/prototypes/steel-companion-full-art-remake/`)에 이미 구현된 내용을 기준으로, 재계획 이전 계약 문서에서 바뀌는 조항을 정리한다. 사용자 체험 승인이 기록되면 확정하고 본 개발의 기준으로 쓴다. 이 문서는 체험 승인을 대신하지 않는다.

## 그대로 유지하는 조항

- 경제: 확률 45/35/15/5, RARE 가중치, 픽업, 10연(스크랩 20·LV3 보장), 스크랩, QP 개발 비용. 체험판은 원본 함수를 그대로 추출해 쓴다.
- 저장을 먼저 시도하고 결과를 확정한 뒤 연출한다. 스킵·닫기·재실행은 재추첨·중복 지급을 만들지 않는다.
- 감소모션에서는 연출 없이 결과를 바로 보여 준다. 키보드 조작, 초점 복귀, 44px 조작 영역.
- 물성은 실제 TS·EL·RA로 표시한다.

## 체험판에만 있는 것 (본 개발에 가져가지 않음)

- 시작 지급(추가 출하 12회·스크랩 60)과 `체험용 자원 채우기` 버튼.
- 별도 저장 키 `steel_companion_prototype_20261109_v1`.

## 본 개발에서 아직 없는 것

체험판은 공방·출하·도감·카드·선행개발만 다룬다. 제작(부품 35), 차고(차량 8), 연구(퀴즈·고객 요구·보증), 웹툰, 백업·복원, PWA는 이전 게임(`src/`)에만 있다. 본 개발의 첫 작업은 이 기능들을 체험판 구조로 옮기는 순서를 정하는 것이다.

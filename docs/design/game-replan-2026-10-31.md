# Steel Companion 게임판 재계획 원칙 · 2026-10-31

이 문서는 게임판을 독립된 수집 게임으로 리메이크하기 위한 기준이다. 2026-10-31 재계획 회의록과 이후 사용자의 직접 결정을 반영한다.
핵심 순서는 **모든 일러스트와 장착 완성 외형의 사용자 승인 → 체험판 개발 → 체험 승인 → 본 개발**이다.
대표 원화 승인만으로 체험판이나 본 개발에 들어가지 않는다. 일러스트 품질이 부족하면 개발을 시작하지 않는다.

## 적용 범위와 문서 작성 당시 상태

아래의 “현재”는 2026-10-31 문서 작성 당시를 가리킨다. 이후 사용자의 직접 지시와 대상별 승인 기록이 후속 작업의 실제 상태를 정한다. 기존 477점은 2026-11-03 전량 승인됐으며, 이후 도금이 B 개편과 차량 마감 변경분은 새 버전으로 별도 검토한다. 완료된 기존 제작·출력 검수를 전체 미완료로 되돌려 해석하지 않는다.

- 적용 범위는 이 프로젝트의 `game-edition/`이다. 교육판 `repo/`의 제품 방향·아트·배포를 변경하지 않는다.
- 현재 허용된 작업은 이 재계획 문서 작성이다. 이 문서의 미래 작업 목록은 이미지 제작·개발·배포 실행 승인을 대신하지 않는다.
- 새 일러스트를 제작하거나 사용자에게 승인받은 상태가 아니다. 전체 일러스트 승인 조건도 아직 통과하지 않았다.
- 현재 앱이 작동하고 기존 검증이 통과했더라도 새 일러스트·게임 체험의 품질 승인을 뜻하지 않는다.
- 후속 작업은 아래 순서를 따른다. 이 문서를 읽었다는 이유로 아트 제작이나 개발을 자동 시작하지 않는다.

사용자의 후속 직접 결정이 회의록의 이전 제안보다 우선한다. 이 문서는 그 결정을 게임판 작업 기준으로 고정한다.
기존 문서와 충돌하는 게임판 아트·표현·착수 순서는 이 문서를 따른다. 충돌하지 않는 데이터·경제·저장·접근성 안전 계약은 유지한다.
과거 승인 이미지·로그·검수 영수증은 기록으로 보존하되 새 아트의 품질 승인으로 승계하지 않는다.

## 제품 원칙

1. **독립된 게임을 만든다.** 교육판의 화면과 표현을 보존하려는 제약을 벗고 수집·감상·출하의 즐거움을 우선한다.
2. **원본 기획을 출발점으로 삼는다.** 원본 명칭·경제·콘텐츠·캐릭터 정체성을 보존하고 교육판은 정확한 정보의 참고 자료로 삼는다.
3. **모든 일러스트를 리메이크한다.** 캐릭터뿐 아니라 장비·부품·차량·배경·무대·기타 그림과 장착 완성 외형까지 같은 품질로 새로 만든다.
4. **원화 자체가 갖고 싶어야 한다.** 프레임·글자·연출 없이도 귀엽고 멋있어야 하며 낮은 별 등급도 같은 기준을 충족한다.
5. **일러스트 품질이 개발의 선행 조건이다.** 전량 사용자 승인 전에는 새 체험판·UI·연출 구현을 진행하지 않는다.
6. **실제 이름이 몰입을 만든다.** 품종명·강종명·철강 용어·이벤트·차량 힌트·퀴즈의 원래 의미를 유지한다.
7. **등급은 읽기 쉽게 표현한다.** 별·프레임·무대로 희소도를 보여 주며 계열·RARE·각성·실제 물성을 구별한다.
8. **전투 수치와 유료 재화를 추가하지 않는다.** ATK·DEF나 가상 전투력 대신 TS·EL·RA 등 실제 물성을 사용한다.
9. **경제 안전과 접근성을 유지한다.** 표시 과정이 재추첨·중복 지급·추가 소비를 일으키지 않게 하고 스킵·감소모션을 보장한다.
10. **품질은 사용자가 직접 승인한다.** 파일 검사·테스트·에이전트 평가는 사용자 아트 승인이나 게임 체험 승인을 대체하지 않는다.

“일러스트 60%, 연출 40%”는 투자 우선순위를 나타내는 방향이다. 측정된 품질 점수나 전량 승인 조건을 줄이는 근거가 아니다.
저장·백업·경제 함수·빌드·검증 자산은 재사용한다. 전면 아트 리메이크가 시스템 전면 재구축을 뜻하지 않는다.

## 보존할 데이터와 경제

원본의 강종 분류·확률·RARE 가중치·스크랩 확정 교환·10연 보장·픽업·QP 개발 조건을 바꾸지 않는다.

### 장착 완성 외형의 완결성

장비 단품 승인과 기본 캐릭터 승인은 장착 완성 외형 승인을 대신하지 않는다.
실제 호환 규칙이 허용하는 모든 장착 결과를 새 스타일로 만들고 사용자가 직접 확인해 승인해야 한다.
손에 쥐는 방식·손가락/장갑과 접점·팔 자세·장비 크기·받침 지지·가림·그림자까지 완성된 외형으로 판정한다.
재질과 광원 방향이 일치해야 하며 얼굴·엠블럼·계열 식별 요소를 장비가 무너뜨려서는 안 된다.

기존 **103호환쌍 / 107면별 배치**는 누락 점검의 출발점이다. 완성 그림 수나 복수 장비 조합의 검수 완료 수가 아니다.
각 소재의 실제 전체 호환 세트와 유효한 복수 조합, 열처리 전/후를 목록에 연결하여 전량 승인 여부를 추적한다.
최종 외형을 단일 래스터로 만들지 분리 레이어로 만들지는 아트 단계에서 정한다. 모든 조합의 단일 파일화를 미리 강제하지 않는다.
어떤 제작 구조든 최종 장착 모습의 완결성과 사용자 직접 승인 의무는 동일하다. 기존 이미지 재사용·좌표 조정만으로 충족하지 않는다.

## 아트 판정과 승인 기록

대표 원화는 GA 레퍼런스에 맞춘 PO·CR, ★2 연질, 열처리 한 쌍을 포함해 방향을 확인한다.
장비 장착 완성 예시·부품·차량·배경도 함께 비교한다. 대표 승인은 나머지 아트 제작을 이어 갈 기준이며 개발 착수 승인이 아니다.
WR·EG·QP까지 각 계열 기준을 확인하고 전량으로 확장한다. PO·CR·GA 승인만으로 여섯 계열이 승인됐다고 보지 않는다.

| 확인 항목 | 사용자에게 제시할 근거 |
| --- | --- |
| 원화 자체의 매력 | 프레임 없는 전신과 레퍼런스 나란히 비교 |
| 작은 화면 식별 | 실제 72px 표시에서 얼굴·실루엣·계열·장비 구분 |
| 같은 인물의 일관성 | 같은 캐릭터의 세 자세/시점에서 얼굴·비율·엠블럼 유지 |
| 낮은 등급의 매력 | ★2·★3의 단순한 무대에서도 갖고 싶은 완성도 |
| 장착의 자연스러움 | 단품과 모든 유효한 완성 외형, 손·받침·가림·재질·빛 비교 |
| 한 세계의 자산 | 캐릭터·장비·부품·차량·무대를 함께 놓은 정적 합성 |
| 제작 파일의 건전성 | ID·면·규격·알파·안전영역·누락·파생 이미지 확인 |

승인 기록은 대상 ID·면·장착 조합, 버전, 파일 SHA-256, 사용한 레퍼런스, 확인 크기, 승인 날짜와 사용자의 명시적 판단을 연결한다.
상태는 승인·수정 요청·대기로 구분한다. 기술 검사 통과나 무응답을 승인으로 바꾸지 않는다.
수정으로 파일·외형이 바뀌면 해당 버전의 승인 여부를 다시 확인한다. 옛 SHA의 승인은 새 파일에 자동 승계하지 않는다.
일괄 승인은 사용자가 직접 확인한 전체 목록과 버전을 명시했을 때 기록한다. 확인하지 않은 조합까지 확대하지 않는다.
대기·반려·누락 항목이 하나라도 있으면 전체 아트 승인 조건은 미충족이다.

## 개발 시작 전후의 경계와 진행 순서

전체 아트 승인 전에는 참조 수집·정체성/스타일 정리·이미지 제작·정적 이미지 합성·콘택트 시트·크기 검토·파일 검사를 수행할 수 있다.
이는 별도로 승인된 아트 작업 범위 안에서의 허용 활동이다. 승인 자료는 정적 이미지로 제시한다.
**새 게임 코드·인터랙티브 미리보기·UI·애니메이션 구현·체험판 브랜치 착수·가짜 대체 이미지 삽입은 전량 승인 뒤로 미룬다.**
“아트와 병행”, “별도 브랜치이므로 가능”, “대표만 먼저 연결”, “임시 그림으로 구조만 검증”을 예외로 사용하지 않는다.

| 순서 | 결과와 다음 단계 조건 |
| --- | --- |
| 1. 출처·레퍼런스 등록 | 원본 정체성, 지정 스타일, 사용 범위, 전체 자산·장착 외형 목록 정리 |
| 2. 대표 아트 승인 | 사용자 직접 판정으로 스타일·제작 가능성 확인; 허용되는 확장은 아트 제작뿐 |
| 3. 전 계열·전 자산 제작 | 모든 캐릭터·장착 외형·장비·부품·차량·무대·기타 일러스트 완성 |
| 4. 전량 아트 사용자 승인 | 전체 목록·버전·SHA와 승인 기록 완비, 대기·반려·누락 없음 |
| 5. 격리된 작은 체험판 | 전량 승인 뒤 작업 사본에서 공방 → 출하 → 카드 → 도감 재열기 구현 |
| 6. 체험 사용자 승인 | 다시 열어 보고 싶은가, 등급별 손맛·다음 수집/제작 목적·10연 감상 확인 |
| 7. 계약 확정·본 개발 | 승인된 체험으로 디자인·테스트 계약 확정 후 본 구현·회귀 검증·최종 통합 검토 |

전량 아트 승인도 게임 체험·본선 통합·배포 승인이 아니다. 체험 승인 전 본 개발을 앞당기지 않는다.
문서 작성 시점(2026-10-31)에는 1단계의 문서 기준을 작성한 상태였으며, 이 문서 자체는 참조 파일 등록·제작·승인 완료의 증빙이 아니다. 후속 제작·승인은 해당 시점의 실제 자산 목록과 사용자 승인 기록으로 확인한다.
전체 일정과 제작 방식은 대표 아트의 수정 횟수·일관성을 확인해 산정한다. 품질을 맞추기 위해 미승인 그림으로 개발을 선행하지 않는다.

## 전량 승인 후 구현할 체험 목표

아래는 확정된 미래 UX 방향이다. 현재 코드 변경이나 체험판 착수 허가가 아니다.

| 항목 | 목표 |
| --- | --- |
| 프레임 | ★2 흑피 다크 → ★3 경면 은청 → ★4 금빛 도금 → ★5 템퍼 컬러 홀로; QP 특별 표시 |
| 무대 | ★2 공방, ★3 제철소, ★4 노을; ★5와 열처리 후 면은 하늘·떠다니는 슬래브·헤일로 |
| 1회 출하 | ★2·★3 약 2.5초, ★4 약 3.5초, ★5 4~5초; 탭 개봉·빛 예고·공개 |
| 10연 | 장당 약 0.2초와 최고 등급 컷인; 종료 후 열 장을 충분히 감상하고 상세를 열 수 있음 |
| 결과 이후 | 새 발견·사용 가능한 부품·다음 수집 목표, 도감에서 같은 캐릭터 다시 감상 |
| 미발견·물성 | 미공개 정보는 숨긴 계열 실루엣, 실제 TS·EL/RA 게이지와 설명 |

결과와 비용은 기존 경제 명령으로 먼저 확정하고 저장을 시도한 뒤 표시한다. 연출은 확정 결과를 읽으며 다시 추첨하거나 지급하지 않는다.
저장 실패를 성공으로 포장하지 않는다. 경고·현재 메모리 결과·백업 접근을 유지하며 영속 저장이 보장됐다고 주장하지 않는다.
언제든 스킵 가능, 감소모션은 지연 없이 즉시 결과, 소리·이미지 실패는 경제 결과와 분리한다.
10연 최종 결과는 자동 소멸시키지 않고 사용자가 감상·상세 열기를 마칠 수 있게 유지한다.
키보드·초점 복귀·대비·터치 조작·중단 정리는 기존 안전 기준을 이어 간다. 연출 세부 시간은 체험 승인으로 다듬는다.

# WR 신규 8면 제작 기록

대상은 `wr-SWRY`, `wr-SWRH`, `wr-CORD`, `wr-CHQ`, `wr-SUJ`, `wr-SPR`, `wr-VLV`, `wr-NHT`의 front와 파생 썸네일이다. 기존 `wr-SWRM`, `eg-SECC`, `qp-1470` 파일럿은 수정하지 않고 전체 11면 검수에 포함했다.

각 불변 원본과 승인 WR 파일럿을 직접 보고 내장 `image_gen.imagegen`으로 개별 제작했다. `*-generation.json`에 정확한 프롬프트·참조·생성 파일 SHA, `*-export.json`에 결정적 크기 변경·투명 여백·WebP 인코딩 명령을 보관한다. 선택된 생성 PNG는 `../masters/character/<id>/front.png`에 바이트 그대로 보관한다. SWRY 투명 배경 점검 수정과 SUJ 동심원→연속 나선 수정의 초기 생성본은 `revisions/`에 별도 보관한다. 수작업 회화·벡터 대체·스크린샷 UI는 사용하지 않았다.

전체 원화는 960×1440, 썸네일은 144×216이며 `*-72.png`는 실제 72×108 검수 출력이다. 고리 안 얼굴과 선재·코일 구조, 구슬과 고리형 사지, 강종별 용접 방울/코드/냉간압조/베어링/스프링/밸브/냉간단조 구조 및 나선 문양을 직접 비교했다. 원본 SWRY의 배 모양 몸통, CHQ의 볼트형 중심, SUJ의 베어링 구체는 강종 고유 형태를 유지한다. EG 편면 도금 대비와 QP 후드·결정 문양도 파일럿에서 재확인했다.

RA를 EL로 바꾸지 않았으며 QP는 개발전용으로 유지한다. 이 작업은 catalog·draw pool·물성·107 장비 배치를 변경하지 않는다. 이미 사용한 fragment는 의도적으로 stale 상태로 남긴다. 자동 검사는 SHA·디코딩·알파·영수증 결박을 확인하며 정체성 의미 자체를 자동 판별한다고 주장하지 않는다. 독립 검수 완료 여부는 상위 작업 증거에서 관리한다.

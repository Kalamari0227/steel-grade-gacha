# CR 씨알 신규 11면

Task 14는 `ssial-270C`, `270D`, `270E`, `270F`, `340W`, `340H`, `440W`, `590Y`, `780Y`, `980Y`, `1470M`의 front만 제작했다. SEDDQ와 1180Y 파일럿은 변경하지 않았다. 각 원본은 내장 `image_gen.imagegen`의 개별 호출로 새로 생성했으며, 생성 파일을 지정 master 경로에 바이트 그대로 복사했다. 단순 재색칠·필터를 새 원화로 집계하지 않는다.

각 `*-generation.json`은 실제 프롬프트, 참조 경로/SHA, 생성 출력 경로/SHA와 master SHA를 남긴다. CQ는 투명 배경 수정 호출 한 번을 추가했고 그 입력/프롬프트/SHA도 revisions에 기록했다. `*-export.json`은 Lanczos 크기 변환, 투명 여백, WebP 인코딩과 실제 알파 계수를 기록한다. 런타임은 960×1440, 썸네일은 144×216, 직접 확인한 표시 증거는 72×108이다.

11개 원본 정체성, 승인 카드·장비 시안, 두 CR 파일럿, 11개 생성 master, 11개 런타임, 실제 72px 파일을 직접 확인했다. 5개 검사 항목은 각 자산의 `*-review.json`에 SHA로 결박했다. 얼굴·문양 보호 사각형과 손 위치는 개별 그림에 맞춰 기록했으며, DQ 문양의 왼쪽 경계를 overlay 검토 후 수정했다. 본 영수증은 제작자의 자기 검수이며 독립 수락 검토를 대체하지 않는다.

투명 이미지 미리보기는 alpha=0 픽셀의 RGB를 노출해 안개/가로 블록처럼 보일 수 있다. 실제 alpha를 적용한 13면 graphite 합성에서는 해당 RGB가 보이지 않는 것을 직접 확인했다. 제작 자산의 알파를 자르거나 배경을 별도로 추출하지 않았다. 전체 13면/72px 및 보호 영역 overlay 증거는 `.omo/evidence/game-edition/game-20261025-01a16bac/task-14/`의 `thirteen-full-contact.png`, `thirteen-72-contact.png`, `protected-rects.png`다(프로젝트 루트 기준 증거 경로; 런타임 의존 아님).

문양은 원형 테두리 안 수평 중앙 띠와 위아래 평행 롤 배열이다. 성형용은 뒤로 흐르는 두 겹 머리와 얇은 접힘, W 계열은 원본의 낮은 구조 능선, 340H는 중앙 능선과 소부 경계, 780Y/980Y는 구조판과 복합 표면, 1470M은 낮은 각진 머리·몸을 유지한다. 코트와 구조판을 LV 전투력으로 해석하지 않는다. 이름·수치·SSR·별·ATK·프레임은 원화에 넣지 않았다.

전체 ssial 검사에는 파일럿 2면을 포함한 13면/26자산이 들어간다. `family-negative`는 파일/계약/SHA/영수증의 실제 거부 검증이며 문양을 자동 인식하는 검사가 아니다. 정식 manifest에 사용한 fragment는 재실행하면 stale로 거부되므로 재병합하지 않는다.

## 생성 프롬프트의 핵심

공통: 중세 연금술사의 호두나무 책상, 양피지, 오래된 황동, 촛불, 수공예 미니어처, 읽기 쉬운 경로와 작은 마법 효과. 실제 국가·회사 표식은 사용하지 않는다.

1. 무역 장벽 디자인: 관세는 동전 갑옷과 철문 방패의 기사, 반덤핑은 붉은 밀랍 봉인의 심판관, 물류비는 과적한 달팽이 수레. 전쟁은 끊어진 무역로의 환경 사건, 공급 차질은 갈라진 강괴 골렘, 경쟁 공방은 입찰서를 든 품위 있는 라이벌 상인.
2. 전투 전경: 도금이·포오·타래·큐피 원화를 정체성 참고로 사용한다. 캐릭터는 경로 옆 황동 받침에 배치한다. 관세 기사·봉인 심판관·물류 수레가 항구를 위협하고, 캐릭터는 화염·보호막·충격파·보랏빛 파편으로 대응한다. 웨이브·계약 신뢰·자원·편성 UI를 포함한다.
3. 근접 장면: 동일한 캐릭터 정체성을 유지하며 포오의 가열, 도금이의 보호막, 타래의 밀쳐내기, 큐피의 파편 마법과 적의 봉인을 강조한다. 과대한 촛불과 깃펜으로 미니어처 크기를 보여준다.

## 기획 제안

- 기본 목표: 무역로와 계약 이행을 지킨다.
- 일반 적, 환경 사건, 경쟁 상대를 구분하여 서로 다른 대응을 만든다.
- 반덤핑은 같은 강종의 반복 배치에 봉인을 거는 판타지 규칙으로 제안했다. 실제 제도의 작동을 재현하는 규칙이 아니다.
- 경쟁 밀은 다른 공방·상단과 계약을 겨루는 별도 라이벌로 다룬다.
- 캐릭터 외형과 UI 수치 등은 탐색 단계의 생성 결과이며, 제작 시 기존 승인 원화와 별도로 검토한다.

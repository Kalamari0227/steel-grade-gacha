나의 공방, 다음 장면들

승인된 금속 피규어 세계를 확장한 제작·연구·차고·설정의 상세 디자인 시안입니다. 모바일 390×844와 데스크톱 1280×900에 대응하며, 화면을 열고 직접 조작할 수 있습니다.

모든 재고·완성·선택 상태는 예시입니다. 실제 저장을 읽거나 쓰지 않습니다. 그림은 기존 원화를 임시로 사용했습니다. 후속 원화 작업의 최종 결과가 아닙니다.

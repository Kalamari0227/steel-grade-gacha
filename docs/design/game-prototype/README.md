# 게임판 상세 상호작용 시안

[화면 목록과 모바일·데스크톱 캡처](review.html) · [프로토타입 열기](index.html)

이 폴더는 독립된 디자인 문서입니다. 실제 게임 코드·경제 상태·사용자 저장을 읽거나 쓰지 않습니다. 재고, 완성, 보유, 백업 토큰은 시연용 예시이며 화면에 이를 표시합니다.

로컬 브라우저에서 `index.html`을 직접 열거나, `game-edition/docs/design`에서 `python3 -m http.server 4387 --bind 127.0.0.1`로 제공한 뒤 `/game-prototype/index.html`을 여세요. 검증용 서버는 검증 종료 후 정리됩니다.

- 제작: 부품 3개 예시, 소재 보유/부족, 검토·취소·확정, QP 연구로 이동과 제작 복귀.
- 연구: QP 슬롯/조건, 퀴즈 정오답, 주문 조건, 보증 설명, 기존 웹툰 3항목 진입 예시.
- 차고: 빈 공간·보유·부품 완료 전환, 로드스터/중형 세단 선택과 대표 전시.
- 설정: 5개 경로 공통 오버레이, Escape/호출 버튼 초점 복귀, opt-in·음소거·음량 0–100, 백업 예시, 명시적 교육 가져오기·요약·회복 코드·취소, 초기화 5초 확인.

공방·도감은 승인 원본을 보여 주는 **디자인 참조 갤러리**입니다. 새 상세 시안의 메뉴 동작과 명확히 구분했습니다. 원본 다섯 장과 임시 원화의 출처는 [provenance.json](../game-reference/provenance.json)에 있습니다. 기존 raster art는 최종 게임용 신규 제작 자산이 아닙니다. CSS/SVG는 UI 아이콘·표면에만 사용하며 피규어·차량 그림을 만들지 않습니다.

제작·연구·차고·설정은 원래 승인 이미지에 없는 새 목적지이므로, 원본의 색·재질·조용한 컨트롤 규칙을 확장했습니다. 픽셀 복제 결과라고 주장하지 않습니다. [DESIGN.md](DESIGN.md)에 재사용 토큰·구성요소·반응형 규칙을 기록했습니다.

검증은 소스 SHA와 실제 HTTP 응답이 일치하는 Chrome에서 수행했습니다. 기본8화면과 스크롤 끝, dialog, 320px 실패/경계 상태를 증거 폴더에 보존했습니다. 실제 소리 재생, 백업 형식 호환, 게임 경제, production 성능 검증은 이 디자인 시안의 완료 주장이 아닙니다.

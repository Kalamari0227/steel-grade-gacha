# 스틸 컴패니언 체험 공방

## 기준과 화면

2026-10-31 재계획과 승인된 원화 목록을 기준으로 삼는다. 공방에 온 수집가는 코일을 한 번 출하하고, 장비가 달린 동료의 전신과 목소리를 확인한 뒤 도감에서 다시 만난다.

Layout: 공방의 가로 원경 위에 출하 코일을 놓고 아래 작업대에 조작부를 붙인다. 도감은 계열별 필터와 카드 격자, 상세는 세로 카드와 정보가 나란히 놓인 네이티브 대화상자다. 680px 이하에서는 상세를 세로로 읽는다. 목록은 문서가, 열린 카드는 대화상자가 스크롤을 맡는다.

## 재질·활자·간격

밝은 테마 한 가지를 제공한다. 종이 바탕 #f6f3ec, 표면 #fffcf6, 본문 #232b2b, 보조 #55594f, 행동용 짙은 청록 #203c3a, 강조 황동 #f5cc75, 경계 #c9bda8, 오류 #82372c, 키보드 포커스 #1963ae를 쓴다. 공방 조명과 금속 반사가 화면의 색을 만든다. 짙은 명암의 글자는 불투명한 바탕 위에 놓는다. 시스템 고딕과 명조를 역할별로 사용한다. 본문 최소 14px, 제목 26–52px, 조작 영역 44px 이상, 간격 4·8·12·16·24·32·48px, 최대 본문폭 1160px. 새 글꼴과 그림을 내려받지 않는다.

## 소재 감상과 동작

일반 LV1–4는 ★2–5, 선행개발 QP는 전용 표식과 무대, RARE는 작은 각인으로 표현한다. 일반 출하 1회는 봉인을 연 뒤 ★2–3 2.6초, ★4 3.4초, ★5 4.2초에 카드가 나온다(2026-11-12 사용자 검토 '너무 빠르게 지나간다' 반영, 이전 1.6·2.2·2.8초). 공개된 카드는 자동으로 넘어가지 않고 `결과 보기` 입력까지 머문다. RARE도 조율 3초 뒤 카드에서 기다린다. 10연은 한 장씩 이름과 새 발견 여부를 보여주고 다음 입력까지 기다린다. PHS를 포함한 RARE의 봉인 예고는 3초이며 역회전 고리·기울어진 궤도·중앙으로 모이는 빛으로 구성한다. 음악은 macOS General MIDI 악기 샘플러로 연주한 7.2초 스테레오 WAV를 사용한다. 어긋난 현악·목관의 음정을 A장조 화음으로 모으고 정확히 3초에 관악을 더해 조율을 완성한다. 브라우저의 오디오 출력 시간을 읽어 고리 수렴과 카드 공개를 맞추고, 동일한 음원을 끝까지 이어 재생한다. 무음·음원 실패는 시각 시계로 공개하며 감소모션은 공개된 화음 구간부터 재생한다. 음소거·스킵·다시 보기·화면 이탈은 진행 중 소리와 대기를 함께 중단한다. 음향은 기본 무음이며 사용자가 켠다. 비교판의 소리 버튼은 현재 구간을 다시 재생하며, 좌우 음향은 독립적으로 제어한다.

미발견은 계열 실루엣과 계열명만 보여 준다. 장착 선택은 승인된 외형 목록 중 하나를 보는 기능이다. 카드 재열기는 이번 세션의 면·장착 선택을 유지한다. 실제 물성 범위를 게이지 옆에 그대로 쓴다. 이미지 실패 시 같은 자리에 설명과 다시 시도를 제공한다. 저장 오류와 연출은 서로 독립적이다. 화면 읽기용 제목, 초점 복귀와 키보드 조작을 제공한다.

## 카드 글귀

모든 일러스트 카드(상세·출하 공개·1회 결과)에 승인된 KO/JA 대사를 새긴다. 원화 파일에 굽지 않고 `stage()`가 글자 층으로 얹는다. 일본어는 오른쪽 세로쓰기로, 구두점 기준 최대 두 줄로 나눈다. 한국어는 하단에 둔다. 글자 상자나 그늘은 쓰지 않고, 카드 크기에 맞춰 굵기가 변하는 짙은 외곽선(일본어 최대 3px·한국어 최대 3.4px)을 두른 밝은 글자로만 읽히게 해 일러스트를 그대로 둔다. 글자색은 ★2–3 상아, ★4–5 금빛, QP 은청이다. 글자 크기는 카드 폭 기준 일본어 4.7%(11–17px), 한국어 5%(11.5–18px)로, 2026-11-12 사용자 검토 "눈에 잘 띄지 않는다, 특히 일본어"를 반영해 키웠다. 카드 폭 209px 이하는 한국어만, 150px 이하는 글귀를 숨긴다. 글귀 층은 `aria-hidden`이며 상세 정보의 한국어 인용과 일본어 문단이 같은 문장을 읽어 준다. 출하 컷인에서는 카드 도착 뒤 짧게 떠오르고, 감소모션에서는 바로 보인다.

체험 검수는 실제 390px·1280px 화면과 새 저장, 복원, 실패 조건을 확인한다. 최종 사용자의 체험 승인은 별도 기록한다.

## 선행개발 (QP) 과제와 LV5 등장

1470급 세 종(씨알 1470M·도금이 1470H·포오 PHS)을 모두 발견하면 도감 위에 선행개발 과제가 열린다. 원본 개발 거래와 같이 마르텐사이트 칸(1470M)·변태조직강 칸(1180Y 씨알 또는 도금이) 재고 1장씩과 스크랩 10장을 쓰고 QP를 한 번만 지급한다. 엔진 `develop()`은 저장을 먼저 시도하고 결과를 확정한다. 다른 탭 변경·조건 부족은 상태를 바꾸지 않는다. 지난 출하 결과는 그대로 둔다.

개발 직후 `hero.mjs`가 전면 LV5 등장을 재생한다. 흐름은 `feature/draw-fx-src`에서 옮겼다: 정전·경고 테이프·심장 박동(0–2초) → 빛기둥(2–3.1초) → 역광 실루엣이 솟아오름(3.1초) → 섬광·배경 폭발·컬러 공개(4.35초) → 이름 띠(5.05초) → 승인 한국어 대사 타자, 일본어 대사(7.2초) → 도감에 등록(7.9초). 그림은 승인 목록의 QP 기본 원화와 `background:qp`만 쓰며, 원래 브랜치의 미승인 `qp_hero.webp`·`qp_hero_bg.webp`는 가져오지 않는다. 음향은 Web Audio 합성으로 상단 소리가 켜져 있으면 처음부터, 꺼져 있으면 연출 안 버튼으로 남은 구간부터 켠다. 건너뛰기·Esc·도감에 등록은 모두 같은 결과로 QP 카드를 연다. 감소모션에서는 연출 없이 카드를 바로 연다.

# 스틸 컴패니언 체험 공방

## 기준과 화면

2026-10-31 재계획과 승인된 원화 목록을 기준으로 삼는다. 공방에 온 수집가는 코일을 한 번 출하하고, 장비가 달린 동료의 전신과 목소리를 확인한 뒤 도감에서 다시 만난다.

Layout: 공방의 가로 원경 위에 출하 코일을 놓고 아래 작업대에 조작부를 붙인다. 도감은 계열별 필터와 카드 격자, 상세는 세로 카드와 정보가 나란히 놓인 네이티브 대화상자다. 680px 이하에서는 상세를 세로로 읽는다. 목록은 문서가, 열린 카드는 대화상자가 스크롤을 맡는다.

| 화면 | 가장 중요한 행동 | 읽는 순서 |
| --- | --- | --- |
| 공방 | 1회 출하 | 출하 코일, 비용과 남은 횟수, 다음 부품의 필요 계열 |
| 개봉 | 코일 봉인 열기 | 포장, 등급별 빛과 무대, 결과 |
| 결과 | 동료 카드 열기 | 새 발견과 재고, 열 장 전체, 다음 수집 목표 |

| 상세 | 동료 감상 | 등급 무대와 전신, 승인 대사, 장착 외형과 실제 물성 |

## 재질·활자·간격

밝은 테마 한 가지를 제공한다. 종이 바탕 #f6f3ec, 표면 #fffcf6, 본문 #232b2b, 보조 #55594f, 행동용 짙은 청록 #203c3a, 강조 황동 #f5cc75, 경계 #c9bda8, 오류 #82372c, 키보드 포커스 #1963ae를 쓴다. 공방 조명과 금속 반사가 화면의 색을 만든다. 짙은 명암의 글자는 불투명한 바탕 위에 놓는다. 시스템 고딕과 명조를 역할별로 사용한다. 본문 최소 14px, 제목 26–52px, 조작 영역 44px 이상, 간격 4·8·12·16·24·32·48px, 최대 본문폭 1160px. 새 글꼴과 그림을 내려받지 않는다.

## 소재 감상과 동작

일반 LV1–4는 ★2–5, 선행개발 QP는 전용 표식과 무대, RARE는 작은 각인으로 표현한다. 일반 출하 1회는 봉인을 연 뒤 ★2–3 2.6초, ★4 3.4초, ★5 4.2초에 카드가 나온다(2026-11-12 사용자 검토 '너무 빠르게 지나간다' 반영, 이전 1.6·2.2·2.8초). 공개된 카드는 자동으로 넘어가지 않고 `결과 보기` 입력까지 머문다. RARE도 조율 3초 뒤 카드에서 기다린다. 10연은 한 장씩 이름과 새 발견 여부를 보여주고 다음 입력까지 기다린다. PHS를 포함한 RARE의 봉인 예고는 3초이며 역회전 고리·기울어진 궤도·중앙으로 모이는 빛으로 구성한다. 음악은 macOS General MIDI 악기 샘플러로 연주한 7.2초 스테레오 WAV를 사용한다. 어긋난 현악·목관의 음정을 A장조 화음으로 모으고 정확히 3초에 관악을 더해 조율을 완성한다. 브라우저의 오디오 출력 시간을 읽어 고리 수렴과 카드 공개를 맞추고, 동일한 음원을 끝까지 이어 재생한다. 무음·음원 실패는 시각 시계로 공개하며 감소모션은 공개된 화음 구간부터 재생한다. 음소거·스킵·다시 보기·화면 이탈은 진행 중 소리와 대기를 함께 중단한다. 음향은 기본 무음이며 사용자가 켠다. 비교판의 소리 버튼은 현재 구간을 다시 재생하며, 좌우 음향은 독립적으로 제어한다.

미발견은 계열 실루엣과 계열명만 보여 준다. 장착 선택은 승인된 외형 목록 중 하나를 보는 기능이다. 카드 재열기는 이번 세션의 면·장착 선택을 유지한다. 실제 물성 범위를 게이지 옆에 그대로 쓴다. 이미지 실패 시 같은 자리에 설명과 다시 시도를 제공한다. 저장 오류와 연출은 서로 독립적이다. 화면 읽기용 제목, 초점 복귀와 키보드 조작을 제공한다.

## 카드 글귀

모든 일러스트 카드(상세·출하 공개·1회 결과)에 승인된 KO/JA 대사를 새긴다. 원화 파일에 굽지 않고 `stage()`가 글자 층으로 얹는다. 일본어는 오른쪽 세로쓰기로, 구두점 기준 최대 두 줄로 나눈다. 한국어는 하단에 둔다. 글자 상자나 그늘은 쓰지 않고, 카드 크기에 맞춰 굵기가 변하는 짙은 외곽선(일본어 최대 3px·한국어 최대 3.4px)을 두른 밝은 글자로만 읽히게 해 일러스트를 그대로 둔다. 글자색은 ★2–3 상아, ★4–5 금빛, QP 은청이다. 글자 크기는 카드 폭 기준 일본어 4.7%(11–17px), 한국어 5%(11.5–18px)로, 2026-11-12 사용자 검토 "눈에 잘 띄지 않는다, 특히 일본어"를 반영해 키웠다. 카드 폭 209px 이하는 한국어만, 150px 이하는 글귀를 숨긴다. 글귀 층은 `aria-hidden`이며 상세 정보의 한국어 인용과 일본어 문단이 같은 문장을 읽어 준다. 출하 컷인에서는 카드 도착 뒤 짧게 떠오르고, 감소모션에서는 바로 보인다.

체험 검수는 실제 390px·1280px 화면과 새 저장, 복원, 실패 조건을 확인한다. 최종 사용자의 체험 승인은 별도 기록한다.

## 선행개발 (QP) 과제와 LV5 등장

1470급 세 종(씨알 1470M·도금이 1470H·포오 PHS)을 모두 발견하면 도감 위에 선행개발 과제가 열린다. 원본 개발 거래와 같이 마르텐사이트 칸(1470M)·변태조직강 칸(1180Y 씨알 또는 도금이) 재고 1장씩과 스크랩 10장을 쓰고 QP를 한 번만 지급한다. 엔진 `develop()`은 저장을 먼저 시도하고 결과를 확정한다. 다른 탭 변경·조건 부족은 상태를 바꾸지 않는다. 지난 출하 결과는 그대로 둔다.

개발 직후 `hero.mjs`가 전면 LV5 등장을 재생한다. 흐름은 `feature/draw-fx-src`에서 옮겼다: 정전·경고 테이프·심장 박동(0–2초) → 빛기둥(2–3.1초) → 역광 실루엣이 솟아오름(3.1초) → 섬광·배경 폭발·컬러 공개(4.35초) → 이름 띠(5.05초) → 승인 한국어 대사 타자, 일본어 대사(7.2초) → 도감에 등록(7.9초). 그림은 승인 목록의 QP 기본 원화와 `background:qp`만 쓰며, 원래 브랜치의 미승인 `qp_hero.webp`·`qp_hero_bg.webp`는 가져오지 않는다. 음향은 Web Audio 합성으로 상단 소리가 켜져 있으면 처음부터, 꺼져 있으면 연출 안 버튼으로 남은 구간부터 켠다. 건너뛰기·Esc·도감에 등록은 모두 같은 결과로 QP 카드를 연다. 감소모션에서는 연출 없이 카드를 바로 연다.

## 등급별 출하 차등 (2026-11-12)

사용자 검토 "★5도 ★2–3과 차별점이 없어 보인다"를 반영했다. 봉인 단계의 예고와 카드 공개를 모두 등급으로 나눈다. ★2–3은 은빛 그대로다. ★4는 공방이 금빛으로 물들고 코일이 금빛으로 맥동하며, 공개 때 금빛 섬광·회전 광륜·금빛 카드 테두리광이 붙는다. ★5는 공방이 어두워지고 코일에서 무지갯빛 기둥이 솟은 뒤 코일이 떨리며 "★5 미래수요제품 신호"를 알리고, 흰 섬광과 함께 카드가 뒤집혀 등장한다. 카드는 더 크고 무지갯빛 광륜과 맥동하는 테두리광, 무지개 등급 글자를 가진다. LV5(QP)는 출하가 아니라 도감의 선행개발 과제에서 개발에 성공할 때 전용 히어로 연출로만 등장한다. 감소모션에서는 기존과 같이 결과를 바로 보여 준다.

도감에서 소재를 누르면 열리는 상세는 카드를 더 크게 보여 준다(모바일 최대 340px, 넓은 화면은 카드 열을 더 넓게).

등급 네 단계를 소리와 그림 모두로 나눈다(2026-11-12 사용자 검토 "레벨이 올라가도 띠로리로 똑같다" 반영). ★2는 녹음된 공개음과 은빛. ★3은 푸른 광택 예고(3.0초)와 푸른 섬광·테두리광, 공개음 위에 맑은 종 두 음. ★4는 상승하는 저음 예고와 금빛 3단 팡파르. ★5는 심장 박동과 상승음 예고 뒤 폭발음과 긴 화음·아르페지오. ★3–5의 추가 소리는 Web Audio 합성이며 소리가 켜져 있을 때만 난다. 10연에서도 카드마다 그 등급의 공개 효과와 소리가 난다.

## 데모 연출 이식 (2026-11-14)

예전 뽑기 연출 데모(`archive/draw-fx`, `game-preview/fx-demo`)와 비교한 뒤, 체험판을 뼈대로 두고 데모의 네 가지를 옮겼다. 그림은 승인 목록의 것만 쓰고 데모용 그림은 가져오지 않았다.

- 봉인 열기: 코일이 받침대에 떨어져 내려앉고, 탭하면 점점 세게 덜컹거리며 틈새로 등급 색 빛이 샌다.
- 카드 등장: 코일이 터지고 카드가 그 자리에서 회전하며 튀어나와 착지한다(회전 수 ★2–3 1회, ★4 2회, ★5·RARE 3회).
- 승급: ★5는 금빛으로 시작했다가 "▲ 등급 상승"과 함께 무지갯빛으로 뒤집힌다. RARE는 기존 특수 봉인 연출을 유지한다.
- 소리: 데모의 합성음(내려앉음, 덜컹거림, 균열, 승급, 터짐, 등급별 종소리)으로 바꿨다. 녹음 파일은 결과음과 RARE 음악만 쓴다. 외주 음원이 오면 `reveal.mjs`의 `TIER_SOUND` 표를 바꾼다.

봉인을 연 뒤 카드가 나오기까지의 길이(2.6/3.0/3.4/4.2초), 등급 네 단계 색, 카드 글귀, 카드에서 멈추기는 그대로다.

## 게임풍 껍데기 U1 (2026-11-14)

사용자가 화면 개편 시안에서 C안을 확정했다([계획](../../../docs/plans/game-ui-redesign-plan-2026-11-14.md)). 이 절이 위의 "밝은 테마 한 가지"와 색 값, 상단 글자 탭 배치를 대체한다. 경제·저장·연출 길이·카드 글귀는 그대로다.

- 바탕: 화면 전체에 고정된 배경 그림(`#backdrop`)을 깔고 문서는 스크롤하지 않는다. 내용은 `#scroller` 안에서만 스크롤한다. 배경은 화면마다 승인 장면을 쓴다: 공방·결과 `scene:workshop:back`, 도감 `scene:collection:back`, 제작·차고·연구는 각 `scene:*:back`. U1에서는 모두 어둡게 누른다. 로비를 밝게 두는 것은 U2의 로비 개편에서 한다.
- 색: 판 `#141a23`(93% 불투명), 본문 `#f4ecd9`, 보조 `#b9b09c`, 황동 `#f5cc75`(밝은 쪽 `#ffe9ae`, 어두운 쪽 `#b98428`, 모서리 `#6f4b12`), 황동 위 글자 `#2a1a02`, 경계 `#5c4d2e`, 오류 `#ff9c8a`, 키보드 포커스 `#7db9ff`.
- 버튼: 주 행동은 황동 입체 버튼, 보조는 강철 버튼. 조작 영역 44px 이상은 그대로다.
- 상단 HUD: 상표, 재화 칩(남은 출하·스크랩), 소리 버튼. 680px 이하에서는 상표 글자를 숨기고 고리 표식만 둔다. 칩은 표시만 하며 `show()`와 출하 확정 직후에 다시 그린다.
- 독: 같은 `nav`를 화면 아래에 고정한다. 900px 이상에서는 왼쪽 세로 독이 된다. 순서는 문서 순서(공방·출하 결과·도감·제작·차고·연구)와 같아 키보드 이동 순서가 보이는 순서와 일치한다. 선택된 칸은 황동판이다. 아이콘은 승인 그림을 줄여 쓴다: 공방 `draw:coil-pack`, 출하 결과 `draw:seal`, 도감 `silhouette:ga`(미발견 동료를 드러내지 않도록 실루엣), 제작 `part:roof`, 차고 `car:b`, 연구 `item:loupe`. 제작·도감은 전용 아이콘을 새로 제작·승인받을 때까지의 임시다.
- 전환: 화면이 바뀔 때 0.24초 떠오름. 감소모션에서는 없다.
- 글꼴: 제목은 CSS 변수 `--display` 하나로 정한다. 지금은 시스템 고딕이며, 사용자가 고른 글꼴 1종을 저장소에 넣으면 이 변수만 바꾼다.
- 배경·독·칩의 그림은 장식이라 불러오지 못하면 조용히 비운다. 카드·장면 그림의 "다시 시도"는 그대로다.

## U2 로비와 출하소 (2026-11-14)

공방 탭이 두 화면으로 나뉜다. 이 절이 위 "기준과 화면" 표의 공방 행을 대체한다.

- **로비(`#workshop`)**: 밝은 노을 공방 배경에 대표 동료의 기본 외형(앞면·장비 없음)이 서 있다. 한국어 승인 대사를 말풍선으로, 별·RARE·이름을 아래에 둔다. 이름을 누르면 동료 카드가 열린다. 아래에 다음 제작 목표와 `코일 출하`(출하소로 이동) 버튼이 있다. 화면 제목(h1)은 `공방`이며 화면 읽기용으로만 둔다. 동료가 한 명도 없으면 코일과 안내 문장을 보여 준다.
- **대표 동료**: 동료 카드의 `로비 대표로 지정`으로 정한다. 지정하지 않았으면 마지막 출하에서 새로 발견한 동료(없으면 그 출하의 마지막 동료), 출하 결과가 없으면 가장 높은 등급의 보유 동료가 선다. 저장에는 지정했을 때만 `featured`(카드 ID)가 생긴다. 보유하지 않은 ID가 들어 있으면 다른 손상과 같이 저장을 보류한다. 엔진 `setFeatured()`는 다른 명령과 같은 다중 탭 검사를 거치며 재고·자원을 바꾸지 않는다.
- **출하소(`#ship`)**: 어두운 공방에 코일과 계열 실루엣 세 개(씨알·포오·도금이)를 둔다. 미발견 동료를 드러내지 않으려고 원화 대신 승인 실루엣을 쓴다. 등급 확률 띠(★5 5% · ★4 15% · ★3 35% · ★2 45%)는 원본 `LVRATE`와 같은 값을 표시용으로 적은 것이며 추첨에는 쓰지 않는다. 원본 확률이 바뀌면 `views.mjs`의 `RATES`도 고친다. 1회·10연 버튼과 체험용 자원 채우기는 이전 공방 화면의 것을 그대로 옮겼다. 독에서는 공방 칸이 선택된 상태로 보인다.
- 이전 공방 화면의 "보유 자원" 줄과 "도감 열기" 띠는 상단 재화 칩과 독이 대신한다.
- 900px 이상에서는 로비가 동료(왼쪽)와 이름·목표·출하 버튼(오른쪽 아래), 출하소가 코일(왼쪽)과 제목·확률·버튼(오른쪽)으로 놓인다.

## U2 도감 격자와 전체 화면 상세 (2026-11-14)

이 절이 위 "기준과 화면"의 상세 설명(세로 카드와 정보가 나란한 대화상자)과 "장착 선택" 조작을 대체한다. 카드 구성(무대·전신·프레임·별·글귀)과 대사·물성 표기는 그대로다.

- **도감·결과 격자**: 타일이 작은 카드가 된다. 발견한 동료는 2:3 칸에 썸네일을 넣고 승인 프레임(`frame:star-2`–`star-5`, `frame:qp-special`)을 겹친 뒤 등급색 테두리와 바탕을 준다(★2 은 `#b8c2cc`, ★3 청 `#6fb6ff`, ★4 금 `#ffcf72`, ★5 `#ff9ad5`와 푸른 빛, QP `#b98cff`). 미발견 타일은 등급 표시 없이 계열 실루엣만 둔다. 프레임 그림은 장식이라 실패하면 비운다.
- **상세**: 같은 `dialog`를 화면 전체로 편다. 뒤에는 그 카드의 무대 그림을 흐리고 어둡게 깐다. 좁은 화면은 카드 아래로 정보판이 이어지고 판 안쪽이 스크롤된다. 900px 이상은 카드(왼쪽, 화면 높이에 맞춤)와 정보판(오른쪽)이 나란하다. Esc·닫기·뒤로 가기 동작은 그대로다.
- **장비 슬롯**: 드롭다운을 슬롯 버튼으로 바꿨다(`#equipment` 묶음 안의 `.slot[data-key]`, `aria-pressed`). 슬롯을 누르면 그 장비를 더하거나 뺀 승인 외형으로 바뀐다. 승인 외형 301개는 카드·면마다 장비의 모든 부분 조합을 갖추고 있어(2026-11-14 확인) 어떤 조합도 승인 목록 밖으로 나가지 않는다. 조합이 없으면 아무 일도 하지 않는다. 여전히 보기 선택이며 소유·장착이 아니다. 슬롯 그림은 `item:*`, 이름은 승인 외형의 장비명이다.

## 제목 글꼴 Hahmlet (2026-11-14)

사용자가 후보 열 가지를 실제 화면에서 비교한 뒤 Hahmlet을 골랐다(둥글고 귀여운 계열은 "너무 아동스럽다"로 제외). 이 절이 위의 "새 글꼴을 내려받지 않는다"와 "시스템 고딕과 명조를 역할별로" 중 제목 부분을 대체한다.

- 파일: `src/fonts/Hahmlet-wght-ko.woff2`(가변 굵기 축소본, 약 0.5MB)와 허가서 `Hahmlet-OFL.txt`(SIL Open Font License 1.1). 출처는 GitHub `google/fonts`의 `ofl/hahmlet/`. `prepare.mjs`가 `public/fonts/`로 복사한다. 외부 주소에서 불러오지 않는다.
- 쓰는 곳: CSS 변수 `--display`가 걸린 제목, 동료 이름, 주요 버튼 글씨, 독 글씨, 상표. 본문·설명·물성 수치·재화 숫자는 시스템 글꼴 그대로다. 카드에 새긴 글귀는 기존 명조 지정을 그대로 쓴다.
- `font-display:swap`이라 글꼴이 오기 전에는 시스템 명조로 먼저 보인다. 글꼴을 불러오지 못해도 같은 대체 글꼴로 남는다.
- 축소: 원본(약 3.6MB)에서 영문·숫자, KS X 1001 완성형 한글 2,350자, 기호 몇 개, 그리고 축소 시점의 소스·자료에 나오는 모든 글자만 남겼다. 굵기 축(100–900)은 그대로다. 지금 화면에 쓰는 한글 614자가 모두 들어 있음을 확인했다. 축소본에 없는 글자는 대체 명조로 나온다. 드문 글자가 제목에 필요해지면 체험판 폴더의 `subset-font.py`로 다시 만든다(원본은 저장소에 두지 않고 출처에서 받는다). 허가서에 예약 글꼴 이름 지정이 없어 이름은 바꾸지 않았다.

진행은 `sgg_game_save_v1`, 별도 표시·음향 설정은 `sgg_game_preferences_v1`을 사용합니다. 게임 백업은 `SGG-GAME1.`입니다. 교육용 `SGG1.`은 설정의 명시적인 교육용 백업 가져오기에서 미리보기와 교체 확인을 거칩니다. 자동 이전과 병합은 없습니다. 저장 거부 시 현재 메모리 결과와 경고·내보내기를 확인하세요. 복구 코드는 페이지 메모리에만 있어 새로고침 전에 따로 보관해야 합니다.

교육용과 별도 origin에서 실행하는 배치를 기본으로 사용합니다. 같은 origin의 실제 분리 경로·SW scope는 해당 검증 근거가 확인한 조건에 한정합니다. 같은 origin의 루트 교육용 SW와 겹치는 배치는 지원하지 않습니다. 오프라인은 핵심 파일과 이미 캐시된 선택 파일에 한정되며, 캐시되지 않은 음악은 무음입니다. 실행 URL은 실행 receipt의 실제 값을 사용합니다.

이 안내는 최종 인수 완료 선언이 아닙니다. 최종 고정본 전체 회귀·최종 보관본·미리보기와 독립 검토·사용자 인수는 각각 해당 근거를 확인해야 합니다.

# 스틸 그레이드 가챠 · 교육용

철강 소재를 캐릭터로 만나고, 도감을 모으며 부품을 제작하는 정적 웹앱입니다. 카드의 수치는 교육용 대표값이며 실제 제품의 규격 보증치가 아닙니다.

> **교육용 보존 버전:** `education-v1` · 2026-10-25. 최종 인수한 앱을 보존한 버전입니다. 복원 방법, 최종 산출물 식별값과 검증 자료의 범위는 [교육용 보존 기록](docs/releases/education-v1.md)을 참고하세요. 아래 기능 설명은 T22 검토를 바탕으로 합니다.

| 화면 | 할 수 있는 일 |

| 도감 | 일반 소재44종과 별도 QP,계열/LV/발견/재고 필터,소재 카드 |

설정에서 진행 백업·복원, 저장 상태, 설치 안내, 알림과 공지·행사에 접근합니다. 브라우저가 지원하는 설치 방식은 설정의 안내를 확인하세요. 설치나 알림 허용 여부는 기기와 브라우저에 따라 다릅니다.

키보드로 도감의 계열·LV 선택과 대화상자를 조작할 수 있습니다. 감소동작 설정에서는 화면 전환 동작을 끕니다. 접근성 검토에서 실제 기본 선택 메뉴의 키보드 조작을 확인했지만, 확대 검증은 CSS640×450/DPR2의 등가 배치로 수행했으며 OS의 실제200% 확대를 확인한 것은 아닙니다. 최종 두 브라우저 전체 회귀 결과는 T23 외부 보고서에서 확인합니다.

## 출하와 스크랩

기본 출하는 마지막 사용 시각을 기준으로24시간 주기로 갱신됩니다. 평상시 기본 몫은1회이며 퀴즈 보상 등으로 받은 추가 몫은 화면에서 따로 표시합니다. 기본 퀴즈 보상 한도는24시간 창에서3회이고, 기간 한정 행사가 한도를 바꿀 수 있습니다. 날짜가 바뀌면 무조건 초기화된다는 뜻은 아닙니다.

| 행동 | 스크랩 | 결과 |
|---|---:|---|
| LV3 확정 교환 |5|해당 등급1장 |
| LV4 확정 교환 |10|해당 등급1장 |
|10연 출하 |20|10장, LV3 이상 최소1장 |

확정 교환은 미발견 소재를 우선합니다. 해당 등급을 모두 발견했어도 교환할 수 있고 재고가 늘어납니다.10연은 기본 출하 주기와 별도로 스크랩을 사용합니다. 결과 전체 보기와 카드 상세를 사용해 재고·처음 발견·중복을 확인할 수 있습니다.

일반 출하의 등급 분포는 LV1 45%, LV2 35%, LV3 15%, LV4 5%입니다. 같은 등급 안의 가중치와 기간별 픽업은 원본 규칙을 따릅니다. QP는 일반 출하 풀에 포함되지 않습니다. 개발자는 확률을 바꿀 때 생성된 index.html 대신 src/app_tpl.html의 LVRATE/RARE/PROMOS를 검토하고 다시 빌드합니다.

## 도감과 재고

도감은 발견 기록, 재고는 지금 소비할 수 있는 장수입니다. 제작으로 재고가0이 되어도 발견 기록과 카드 정보는 남습니다. 같은 소재를 다시 얻으면 재고가 늘어납니다. NEW 표시는 이번 실행에서 출하 결과로 확인한 최초 발견 표시이며 별도 저장 필드가 아닙니다.

카드에는 이름·계열·사업 LV·재고·ID·대표 TS와 EL 또는 RA·용도·장착 보증 항목이 나옵니다. LV는 사업 분류여서 모든 물성의 우열이나 강도 순위를 나타내지 않습니다. 예를 들어 S-EDDQ와1180Y는 같은 LV3여도 대표 물성과 용도가 다릅니다.

- 일반 소재44종 + 선행개발 QP1종 =45 ID.
- PHS와 Al-Si HPF는 같은 ID의 전/후 상태를 각각 보여 주므로 그림은47개입니다.
- 이 도감의 선재9종은 단면수축률 RA(%), 나머지는 연신율 EL(%)를 표시합니다.
- TS의 단위는 MPa입니다. 대표값은 두께·열처리·시험편·시험조건을 특정한 제품 사양을 대신하지 않습니다.
- GA 캐릭터 계열에 포함된 ga-1470H의 실제 표면 표기는 Al-Si입니다. 게임 계열 분류가 GA와 Al-Si를 동일 도금으로 정의하지 않습니다.

기술 표현의 출처와 남은 한계는 [교육 내용 검토](docs/learning-content-review.md)에 기록합니다.

## 부품35종과 차고8종

부품마다 필요한 슬롯과 후보 소재가 있습니다. 선택 화면의 실제 소비 예정 수량을 확인하고 제작합니다. 제작한 부품은 같은 차를 준비하는 동안 완료 상태가 됩니다.35부품을 모두 갖추면 아직 보유하지 않은 완성차를 선택할 수 있으며, 차량을 받으면 해당 부품을 소비하고 다음 차를 준비합니다.8종 모두를 모은 상태는 차고에서 확인합니다.

원본35부품 레시피에는 총42슬롯이 있습니다. 일반 소재로 채운 슬롯은 재고를 소비하지만 QP로 대체한 적격 슬롯은 무소모이므로, 차량당 재고 소비를 항상42장 또는8대336장으로 단정하지 않습니다. 화면의 선택 결과가 소비량 기준입니다.

SWRM·SWRY·SWRH는 현재 게임의 부품 후보에 포함되지 않습니다. 이것을 실제 자동차 산업에서 쓰이지 않는다는 뜻으로 일반화하지 않습니다.

## 별도 선행개발 QP

씨알1470M, 도금이1470H, 포오PHS를 모두 발견하면 과제가 공개됩니다. 발견과 개발 재료 재고는 별개입니다.

개발에는 씨알1470M1장, 씨알 또는 도금이1180Y1장, 스크랩10이 필요합니다. 최초 개발1회로 QP를 얻으며 일반44종의 분모와 따로 표시합니다.

QP는 후보에1470M·1470H·PHS가 포함된 슬롯만 대신 채울 수 있습니다. 적격 슬롯의 QP 선택은 무소모이고, 일반 소재를 명시적으로 선택하면 그 재고를 소비합니다. B필러의980급 보강 슬롯 등 비적격 슬롯은 그대로 필요합니다. 부품 전체나 모든 제작을 무료로 만드는 기능이 아닙니다.

이 재고 조합은 게임 개발 비용입니다. 실제 Q&P 열처리 공정을 두 카드의 혼합 제조법으로 설명하지 않습니다.

## 퀴즈·고객 요구·보증

퀴즈는 기존413문항에서 출제되며 선택지 순서를 섞습니다. 채점 뒤 기존 해설과 보상을 구분해서 확인합니다. 본 프로젝트의 데이터 보존 검사가413문항 각각의 과학적 정확성을 인증하는 것은 아닙니다.

고객 요구에 맞는 보증 항목을 선택하고, 보유한14개 보증 항목의 원본 호환 범위에 맞는 발견 소재에 장착합니다. 장착은 재고 소비나 대표 물성 숫자 상승을 뜻하지 않습니다. 요구·호환·보상 규칙은 기존 데이터를 따릅니다.

## 공방 이야기

공방의 이야기 진입 또는 학습의 웹툰 버튼에서 목록을 엽니다. 기존 소개편과1·2화, 본문15장/썸네일3장을 유지합니다. 소개편의 다섯 캐릭터는 해당 계열 도감으로 연결되고 읽던 위치로 돌아올 수 있습니다.

NEW는 가장 나중 순서의 열어본 회차 ID를 기준으로 합니다. 완독·학습 완료 기록이 아닙니다. 페이지가 아직 로딩 중이거나 실패했으면 상태와 재시도를 확인하세요. 오프라인에서는 실제로 내려받아 기기에 남아 있는 그림만 다시 볼 수 있습니다. 회차를 열기만 했다고 모든 lazy 페이지가 저장되는 것은 아닙니다.

## 백업·복원과 저장

진행은 해당 브라우저의 localStorage와 IndexedDB 사본에 저장됩니다. 기기·브라우저를 바꾸거나 사이트 데이터를 삭제하면 자동으로 따라오지 않습니다. 설정의 진행 백업·복원에서 SGG1 코드를 보관하세요.

SGG1에는 원본 형식의 진행 필드만 들어갑니다. 별도 웹툰 seen 키 등 모든 브라우저 상태를 포함하는 전체 복제본은 아닙니다. 복원·저장 진단 화면의 실제 결과를 확인하며, 저장이 거부된 경우 성공으로 가정하지 않습니다. 진행 초기화는 기존5초 이내 두 번 확인 동작을 따릅니다.

유효한 코드를 복원하면 열린 창의 내 백업 코드와 요약도 복원된 진행으로 갱신됩니다. 창을 다시 열지 않고 바로 복사할 수 있습니다. 읽을 수 없는 코드는 기존 진행·출력 코드·요약을 바꾸지 않습니다.

업데이트 시 기존 앱 캐시에 있는18개 허용 웹툰 경로의 정상 이미지 응답만 새 캐시로 이전합니다. 복사에 실패하면 해당 이전 캐시를 남기며, 아직 저장되지 않은 그림을 오프라인에서 새로 내려받을 수는 없습니다. 검증에서는 Chromium의 브라우저 오프라인과 WebKit의 테스트 서버 연결 중단을 구별했습니다. 실제 기기의 OS 설치나 기기 전체 오프라인을 모두 검증했다는 뜻은 아닙니다.

알림은 사용자가 켜는 기능이며 서버 푸시를 제공하는 구조가 아닙니다. 앱이 닫혀도 반드시 알림이 온다고 보장하지 않습니다.

# 최신 승인본 사용 기준 · 2026-11-11

현재 제품은 **스틸 컴패니언 게임판**이다. [캐릭터 47면](index.html)과 [477개 파일 목록](artwork.json)을 게임·영상 제작의 진입점으로 사용한다.

## 무엇이 최종본인가

- 원화 선택은 사용자 승인 카탈로그 SHA `df6a3d818f0a8617db7dda8a58f4365821aa2419b11c3b6c0604957bb445300c`로 고정한다. 파일 수정 날짜나 `final`, `v4`, `v5` 같은 이름의 순서로 선택하지 않는다.
- 원화 승인은 11월 3일 전량 승인과 11월 6일 개편·차량 후속 승인 기록에 연결된다. 11월 9일은 원화·문안·장착 배치 승인 기록의 종합 감사일이다. 이를 모든 그림을 11월 9일 다시 제작했다는 뜻으로 해석하지 않는다.
- 기본 47면과 장착 254개가 실제 캐릭터 외형이다. 나머지 176개는 부품·차량·무대·배경·파생 이미지·시점 참고 등이다. 시점 참고 자료를 기본 캐릭터 대신 사용하지 않는다.
- 도금이는 낮고 넓은 둥근 사각 헬멧 B형이다. 타래는 두꺼운 코일 헬멧·몸체와 단단한 부츠를 쓴다. PHS는 `df-r1-production-v1`의 최신 승인 포즈를 사용한다.
- 체험판에는 기본·장착 301개와 KO/JA 문안 47쌍이 연결돼 있다. 아트 승인과 체험 품질 승인은 별개이며 체험 품질은 검토 중이다.

## 보관과 Git

`artwork.json`의 `path`는 이 Git 저장소 루트 기준 실제 승인 산출물이다. 기존에 보존된 같은 SHA 파일은 재사용하고, 이전 커밋에 없던 30개만 `supplemental/`에 추가했다. 저장소 복제본에서도 477개를 모두 확인할 수 있다.

`approval/`는 선택 카탈로그·사용자 결정·감사·문안의 원문 JSON 15개를 수정 없이 복사한 보존본이다. 새 승인으로 작성하거나 과거 판정을 고쳐 쓰지 않았다. 보존본별 SHA는 `artwork.json`의 `sources`에 있다.

`localSource`와 `localMaster`는 로컬 원화 보관소 `.omo/artwork/steel-companion-full-art-remake/` 기준 경로다. 생성 원본과 전체 과거 승인·반려 이력 7.4GiB는 로컬에서 원래 위치에 보존한다. Git에 모든 생성 원본을 올렸다는 뜻은 아니다.

## 검증·갱신

게임 저장소 루트에서 `python3 tools/verify-current-art.py`를 실행한다. 승인 산출물 SHA, 사용자 승인 스냅샷, 체험판 외형·문안, 갤러리 로컬 링크를 확인한다. 게임 저장·경제 상태는 변경하지 않는다.

`python3 tools/prepare-current-art.py`는 현재 고정된 승인 자료로 목록과 갤러리만 다시 만든다. 원화나 체험판 실행 파일을 수정하지 않는다. 새 사용자 승인으로 기준이 바뀔 때는 카탈로그와 문안 SHA 및 검증 기준을 함께 갱신하고 검증한다. 기존 승인 기록은 보존한다.
